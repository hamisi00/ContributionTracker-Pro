# PWA Icons Guide

## Required Icons

For the PWA to work properly, you need to create icons in the following sizes and place them in this directory:

### Icon Sizes Needed
- `icon-72.png` - 72x72 pixels
- `icon-96.png` - 96x96 pixels
- `icon-128.png` - 128x128 pixels
- `icon-144.png` - 144x144 pixels
- `icon-152.png` - 152x152 pixels
- `icon-192.png` - 192x192 pixels
- `icon-384.png` - 384x384 pixels
- `icon-512.png` - 512x512 pixels

Also needed:
- `icon.png` - Main icon (at least 192x192)
- `icon.ico` - For browsers (16x16, 32x32, 48x48 combined)

## Design Guidelines

### Visual Concept
The icon should represent financial tracking/contributions:
- 💰 Money/coins
- 📊 Growth/progress chart
- 🎯 Target/goal
- 🤝 Community/group
- Or combination of these concepts

### Design Requirements
1. **Simple & Clear**: Recognizable at small sizes
2. **High Contrast**: Works on both light and dark backgrounds
3. **Brand Colors**: Use the app's purple gradient (#667eea to #764ba2)
4. **No Text**: Icons should be visual only (text doesn't scale well)
5. **Square Canvas**: All icons should be square (1:1 ratio)
6. **Padding**: Leave 10% padding around the edges

### Recommended Design
A circular badge with:
- Purple gradient background (#667eea to #764ba2)
- White dollar sign ($) or coins symbol in center
- Optional: Small upward arrow indicating growth
